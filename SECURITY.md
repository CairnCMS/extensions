# Reporting Security Vulnerabilities

**If you believe you have discovered a security issue in a first-party CairnCMS extension, please open a new private
security vulnerability report through https://github.com/CairnCMS/extensions/security/advisories/new. Alternatively,
reach out to us directly over email: [security@cairncms.dev](mailto:security@cairncms.dev).**

First-party extensions follow the same disclosure process as the
[CairnCMS core project](https://github.com/CairnCMS/cairncms/blob/main/SECURITY.md). Please follow responsible
disclosure practices. Do not publish a vulnerability before a fix is released, and do not divulge exact details or
proof-of-concept exploits ahead of the fix.
