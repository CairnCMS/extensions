# Changelog

All notable changes to `@cairncms/extension-address-completion` are documented in this file. Releases are listed in reverse chronological order. Versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-10

- Initial release: a Google Places address autocomplete interface that saves one compact address record, a display for the saved value, and a confined endpoint that keeps the Google key server-side. An optional embedded map is available per field.
