# CairnCMS Extensions

First-party extensions for [CairnCMS](https://github.com/CairnCMS/cairncms), officially built and maintained by the
CairnCMS project.

Every extension in this repository publishes to npm under the `@cairncms` scope and installs like any other CairnCMS
extension: unpack the published package into your project's `extensions` folder, add it as an npm dependency, or bake
it into a custom Docker image. Each package's README walks through the options for different deployments.

## Extensions

| Extension | Description | Types |
| --- | --- | --- |
| [Live Preview](packages/live-preview) | Preview items on your site in a split pane beside the item editor | Item View |

Each package's README covers its installation, configuration, and
operator notes.
