# CairnCMS Extensions

First-party extensions for [CairnCMS](https://github.com/CairnCMS/cairncms), officially built and maintained by the
CairnCMS project.

Every extension in this repository publishes to npm under the `@cairncms` scope and installs like any other CairnCMS
extension. Add the package as a dependency of your CairnCMS project and restart the instance:

```bash
pnpm add @cairncms/extension-<name>
```
